## Change your password

Account settings has a **Change password** dialog. Enter the current password
and a new one, and the change is made without signing out.

- `POST /api/auth/me/password` takes `current_password` and `new_password` and
  answers `204`. A wrong current password or an empty new one answers `400`
  with the field that failed
- Two overlapping requests cannot both succeed: the new hash replaces only the
  one that was verified
- `@rustrak/client` exposes it as `auth.changePassword()`
- The dialog is translated into all five dashboard languages

## Improvements

- An alert rule with a cooldown of zero or less fires on every matching event,
  and the cooldown is checked against the rule's current value rather than the
  one loaded when the alert started ([@jav-ed](https://github.com/jav-ed))
